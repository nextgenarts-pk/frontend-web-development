# 📅 Day 4 — Branching Mastery

## 🎯 Today's Goals

* Understand branches
* Create new branches
* Switch branches
* Delete branches

---

## 📖 Lesson Content

### Create Branch

```bash
git branch feature-navbar
```

---

### View Branches

```bash
git branch
```

---

### Switch Branch

```bash
git switch feature-navbar
```

or

```bash
git checkout feature-navbar
```

---

### Create + Switch Together

```bash
git switch -c feature-footer
```

---

### Delete Branch

```bash
git branch -d feature-navbar
```

---

## ✍️ Hands-On Exercise

* Create 2 branches
* Add different changes
* Switch between branches
