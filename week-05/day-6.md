# 📅 Day 6 — GitHub Workflow & Collaboration

## 🎯 Today's Goals

* Connect GitHub repository
* Push code
* Pull changes
* Clone repositories

---

## 📖 Lesson Content

### Connect GitHub Repo

```bash
git remote add origin REPOSITORY_URL
```

---

### Push Code

```bash
git push -u origin main
```

---

### Clone Repository

```bash
git clone REPOSITORY_URL
```

---

### Pull Changes

```bash
git pull origin main
```

---

### View Remote

```bash
git remote -v
```

---
