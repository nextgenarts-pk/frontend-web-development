## 📖 Lesson Content

## ✍️ 1. What is Typography in CSS?

Typography means **text styling in websites**.

---

## 🔤 2. Font Properties

### Font Size

```css id="f1a1bb"
p {
    font-size: 20px;
}
```

### Font Family

```css id="f2b2cc"
p {
    font-family: Arial;
}
```

### Font Weight

```css id="f3c3dd"
p {
    font-weight: bold;
}
```

---

## 📏 3. Text Alignment

```css id="t1a2bb"
h1 {
    text-align: center;
}
```

---

## 📐 4. Line Height

```css id="l4h5mm"
p {
    line-height: 1.5;
}
```

---

## 🎨 5. Text Decoration

```css id="d6e7nn"
a {
    text-decoration: none;
}
```
