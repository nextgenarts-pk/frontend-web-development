# Introduction

## What is GitHub?

[GitHub](https://github.com?utm_source=chatgpt.com) is an online platform used to store, manage, and share coding projects.

Developers use GitHub to:

* Save projects online
* Work with teams
* Track project changes
* Create coding portfolios
* Share projects with others

---

# Why is GitHub Important?

GitHub is important because it helps developers:

* Keep project backups
* Collaborate with teams
* Manage code easily
* Track updates and changes
* Show projects professionally

---

# Creating a GitHub Account

## Steps to Create a Profile

1. Open [GitHub Official Website](https://github.com?utm_source=chatgpt.com)
2. Click on **Sign Up**
3. Enter:

   * Username
   * Email
   * Password
4. Verify your account
5. Complete your profile setup

---

# Important GitHub Terms

| Term              | Meaning                        |
| ----------------- | ------------------------------ |
| Repository (Repo) | A project folder on GitHub     |
| Commit            | Saving changes                 |
| Push              | Uploading code to GitHub       |
| Branch            | Different version of a project |
| Clone             | Downloading a repository       |

---

# How to Create a Repository

## Steps

1. Login to GitHub
2. Click **New Repository**
3. Enter repository name
4. Click **Create Repository**

```bash id="0x5po0"

```

### Push Project

```bash id="sflfzh"

```

# What is a Commit?

A commit is used to save project changes with a message.

### Example

```bash id="o16ypr"
git commit -m "Added login page"
```

This command saves the latest changes in the project.
