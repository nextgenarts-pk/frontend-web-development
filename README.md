# 🌟 Week 1 Frontend Web Development Plan (1 Hour Classes)

Ye plan specially beginners ke liye hai jinko web development ka bilkul knowledge nahi.
Har class sirf **1 hour** ki hogi.

---



# 📅 Day 2 — How Internet Works

## ⏰ Class Breakdown

### ⏱️ 0–10 min → Revision

* Previous class discussion

### ⏱️ 10–25 min → Theory

* Internet kya hai?
* Browser kya hota hai?
* Client & Server

### ⏱️ 25–40 min → URL & HTTPS

Example:

```text
https://youtube.com
```

Explain:

* HTTPS
* Domain Name

### ⏱️ 40–55 min → Practical

* Chrome open
* URLs observe
* HTTPS padlock check

### ⏱️ 55–60 min → Homework

3 URLs ke parts identify karo
