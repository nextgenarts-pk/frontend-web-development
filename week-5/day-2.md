## 📖 Lesson Content

### What is Git?

**Git** is a **Version Control System**.

It helps developers:

* Track changes
* Save code history
* Work in teams
* Manage projects safely

---

### Check Git Version

```bash
git --version
```

---

### Configure Git

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

---

### Create Repository

```bash
git init
```
---

### Check Status

```bash
git status
```
---

### First Commit

```bash
git add .
git commit -m "Initial commit"
```
