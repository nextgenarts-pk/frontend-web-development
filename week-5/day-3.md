# 📅 Day 3 — Staging & Commit Mastery

## 🎯 Today's Goals

* Learn staging area
* Understand commits
* Track file changes

---

## 📖 Lesson Content

### Git Add

Add single file:

```bash
git add index.html
```

Add all files:

```bash
git add .
```

---

### Git Commit

```bash
git commit -m "Added homepage layout"
```

---

### Git Log

View commit history:

```bash
git log
```

Short version:

```bash
git log --oneline
```

---

### Git Diff

See changes:

```bash
git diff
```

---

## ✍️ Hands-On Exercise

* Edit files
* Use `git status`
* Add changes
* Create multiple commits

---
