# 📘 Explanation

Operators are special symbols used to perform operations on values and variables.

They help programmers:

- Add numbers
- Compare values
- Store data
- Check conditions
- Create logic in programs

---

# 📘 Arithmetic Operators

Arithmetic operators are used for mathematical calculations.

---

## 🔹 Addition `+`

Used to add two values.

## 💻 Example

```javascript
let a = 10;
let b = 5;

console.log(a + b);
```

### 📝 Output

```javascript
15;
```

---

## 🔹 Subtraction `-`

Used to subtract values.

## 💻 Example

```javascript
let a = 10;
let b = 5;

console.log(a - b);
```

### 📝 Output

```javascript
5;
```

---

## 🔹 Multiplication `*`

Used to multiply values.

## 💻 Example

```javascript
let a = 10;
let b = 5;

console.log(a * b);
```

### 📝 Output

```javascript
50;
```

## 🔹 Division `/`

Used to divide values.

## 💻 Example

```javascript
let a = 10;

console.log(a / b);
```


# 📘 Assignment Operators

Assignment operators assign values to variables.

---

## 🔹 Assignment `=`

Stores a value in variable.

## 💻 Example

```javascript
let age = 17;
```

---

## 🔹 Add and Assign `+=`

Adds value and stores result.

## 💻 Example

```javascript
let num = 10;

num += 5;

console.log(num);
```

### 📝 Output

```javascript
15;
```

---

## 🔹 Subtract and Assign `-=`

Subtracts value and stores result.

## 💻 Example

```javascript
let num = 10;

num -= 3;

console.log(num);
```

### 📝 Output

```javascript
7;
```

---

## 🔹 Multiply and Assign `*=`

Multiplies value and stores result.

## 💻 Example

```javascript
let num = 5;

num *= 2;

console.log(num);
```

### 📝 Output

```javascript
10;
```

---

## 🔹 Divide and Assign `/=`

Divides value and stores result.

## 💻 Example

```javascript
let num = 20;

num /= 4;

console.log(num);
```

### 📝 Output

```javascript
5;
```

# 📘 Comparison Operators

Comparison operators compare two values.

They return:

- `true`
- `false`

---

## 🔹 Equal To `==`

Checks if values are equal.

## 💻 Example

```javascript
console.log(5 == 5);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 Strict Equal `===`

Checks value and data type.

## 💻 Example

```javascript
console.log(5 === "5");
```

### 📝 Output

```javascript
false;
```

---

## 🔹 Not Equal `!=`

Checks if values are different.

## 💻 Example

```javascript
console.log(5 != 3);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 Greater Than `>`

Checks if left value is greater.

## 💻 Example

```javascript
console.log(10 > 5);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 Less Than `<`

Checks if left value is smaller.

## 💻 Example

```javascript
console.log(3 < 5);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 Greater Than or Equal `>=`

## 💻 Example

```javascript
console.log(10 >= 10);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 Less Than or Equal `<=`

## 💻 Example

```javascript
console.log(5 <= 8);
```

### 📝 Output

```javascript
true;
```

# 📘 Logical Operators

Logical operators are used to combine conditions.

---

## 🔹 AND `&&`

Returns `true` if both conditions are true.

## 💻 Example

```javascript
console.log(5 > 3 && 10 > 5);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 OR `||`

Returns `true` if one condition is true.

## 💻 Example

```javascript
console.log(5 > 10 || 10 > 5);
```

### 📝 Output

```javascript
true;
```

---

## 🔹 NOT `!`

Reverses the result.

## 💻 Example

```javascript
console.log(!(5 > 3));
```

### 📝 Output

```javascript
false;
```

---

# 💻 Full Practice Code

```javascript
let a = 10;

console.log(a < 5 || b < 10);
```
