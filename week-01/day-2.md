## 📖 3. HTML Boilerplate Introduction

```html id="pl3x1m"
<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>

</body>
</html>
```

### 4. Boilerplate Tags Explanation

* `<!DOCTYPE html>` → Tells browser this is an HTML5 document
* `<html>` → Root of the webpage
* `<head>` → Contains page information
* `<meta>` → Hidden information (used by browser and Google)
* `<title>` → Website title shown in browser tab
* `<body>` → Main visible content of webpage
