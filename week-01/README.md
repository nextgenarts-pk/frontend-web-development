# 📅 Week 1: Introduction to Frontend Web Development & HTML Basics

Frontend Web Development Course | NextGen Arts

## 🎯 Week 1 Learning Objectives
By the end of this week, students will be able to:

* 🌐 Understand what the Internet is and how websites work
* 🖥️ Learn the Client-Server Model and DNS basics
* 🏗️ Understand frontend vs backend development
* 📝 Write basic HTML5 documents
* 🎨 Understand the role of HTML, CSS, and JavaScript
* 💻 Set up and use VS Code
* 🔗 Create links, images, lists, tables and Form in HTML
* 🚀 Build a complete Personal Bio webpage project
