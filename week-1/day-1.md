# 📅 Day 1 — Introduction to Web Development

## ⏰ Class Breakdown (1 Hour)

### ⏱️ 0–10 min → Introduction

* Teacher introduction
* Students se poochna:

  * کون کون websites use karta hai?
  * Website kya hoti hai?

### ⏱️ 10–25 min → Theory

* What is Web Development?
* Frontend vs Backend
* HTML, CSS, JavaScript introduction

### ⏱️ 25–40 min → Real Examples

* YouTube
* Facebook
* Google

Explain:

* Text = HTML
* Design = CSS
* Buttons/Actions = JavaScript

### ⏱️ 40–55 min → Activity

Students:

* 5 favorite websites likhen
* Un me kya acha lagta hai wo batayen

### ⏱️ 55–60 min → Homework

Homework:

* 5 websites ke purpose likho
