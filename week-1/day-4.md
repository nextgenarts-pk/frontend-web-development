
# 📅 Day 4 — Links, Images & Tables

## 🎯 Today's Goals

* Learn links

---

## 📖 Lesson Content

### 1. Anchor Tag

```html id="o6k3r9"
<a href="https://google.com">Open Google</a>
```

---

### 2. Image Tag

```html id="y7d1m8"
<img src="image.jpg" alt="Image">
```

---

### 3. Table Tags

```html id="p1t4e6"
<table bord="1">

<caption>Student Data</caption>

<thead>
<tr>
<th>Name</th>
<th>Class</th>
</tr>
</thead>

<tbody>
<tr>
<td>Ali</td>
<td>8</td>
</tr>
</tbody>

<tfoot>
<tr>
<td colspan="2">End</td>
</tr>
</tfoot>

</table>
```

---

### 4. Colgroup Tag

```html id="g5u7r2"
<colgroup>
   <col span="1">
</colgroup>
```
