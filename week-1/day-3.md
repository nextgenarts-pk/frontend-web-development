## 📖 Lesson Content

### 1. Lists

#### Unordered List

```html id="d4r9g1"
<ul>
   <li>Apple</li>
   <li>Mango</li>
</ul>
```

#### Ordered List

```html id="5n2s9k"
<ol>
   <li>HTML</li>
   <li>CSS</li>
</ol>
```

---

### 2. Special Tags

```html id="q4f2m1"
<abbr title="Hyper Text Markup Language">HTML</abbr>

<address>
Bagh, Azad Kashmir
</address>

<span>Inline Text</span>

<div>Block Section</div>
<header>Block element</header>
<nav>Navigation</nav>
<section>Block element </section>
<footer>Block element </Footer>
```

---

### 3. Subscript & Superscript

```html id="m8a3x7"
H<sub>2</sub>O

x<sup>2</sup>
```

---

### 4. Deleted & Inserted Text

```html id="v2s8t1"
<del>Old Price</del>
<ins>New Price</ins>
```

---

### 5. BDO Tag

```html id="j9p6c3"
<bdo dir="rtl">Hello</bdo>
```
